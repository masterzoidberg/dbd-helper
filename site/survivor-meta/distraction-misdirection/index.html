Overview

Distraction / Misdirection is a coherent but situational strategic plan with narrower activation or payoff. Its primary role is Misdirection, with secondary emphasis on Chase avoidance. The canonical reason players run it is Create rotations or waste Killer time indirectly.

How It Works
